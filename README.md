# Spotify Top 200 Albüm Veri Analizi

## Canlı Rapor

https://aydasuclk.github.io/Top200_Album_Data_Analysis/

## GitHub Deposu

https://github.com/AydasuCLK/Spotify_TOP200_Album_Analysis

## Proje Hakkında

Bu çalışma İstanbul Ticaret Üniversitesi Veri Analizi dersi kapsamında hazırlanmıştır.

Spotify Top 200 Albüm veri seti kullanılarak keşifsel veri analizi gerçekleştirilmiştir. Çalışmada şarkı süreleri, müzik türleri, sanatçı dağılımları, argo kullanımı, korelasyon analizi ve aykırı değer incelemeleri yapılmıştır.

## Veri Seti

Analizde Spotify Top 200 Albüm veri seti kullanılmıştır.

**Toplam gözlem sayısı:** 2586

**Kullanılan değişkenler:**

- Albüm Adı
- Sanatçı
- Çıkış Tarihi
- Şarkı Adı
- Şarkı Süresi (Saniye)
- Şarkı Sırası
- Argo Kullanımı
- Şarkı Türü

## Yapılan Analizler

- Şarkı sürelerinin dağılımı
- Şarkı türlerinin dağılımı
- Sanatçı frekans analizi
- Ortalama şarkı süreleri analizi
- Argo kullanım oranı analizi
- Korelasyon analizi
- Aykırı değer analizi (IQR)
- Tanımsal istatistikler
- Plotly etkileşimli grafikler

## Kullanılan Teknolojiler

- Python
- Pandas
